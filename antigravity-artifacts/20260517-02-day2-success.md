## Bugs found and fixed during Day 2

1. **`TextDirection` import conflict** — `intl/intl.dart` re-exports `TextDirection` which clashes with `flutter/material.dart`. Fixed with `import 'package:intl/intl.dart' hide TextDirection;`
2. **`Completer` not defined** — missing `import 'dart:async';` in voice.dart
3. **Unused model import** — chat_screen.dart didn't need `models/types.dart` directly
4. **`MyApp` reference in default test** — replaced auto-generated `MyApp` smoke test with one for `TapKarApp`
5. **Partial NDK download from interrupted build** — `[CXX1101] NDK ... did not have a source.properties file`. Fix: `Remove-Item -Recurse $LOCALAPPDATA\Android\Sdk\ndk`, re-run build. Lesson: never kill a Flutter Android first-build mid-NDK-install.
6. **`screencap > file` corrupts PNG in PowerShell** — PowerShell encodes binary output as text. Fix: `adb shell screencap -p /sdcard/screen.png` then `adb pull` to host.
7. **Notification shade overlay on first launch** — confused screenshot capture. Fix: `adb shell input keyevent KEYCODE_BACK` to dismiss.

The Day 4 plan: build a release APK with the deployed Cloud Run backend URL baked in, then upload to **Firebase App Distribution** (or Google Drive) to get a public install link.

